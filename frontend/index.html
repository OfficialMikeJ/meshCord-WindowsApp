Discovery

Control whether this server — and the whole node — can be found in the Discover tab.

Node Discovery Admin

Allow discovery on this node
Master Admin switch. Off = the node is fully private: its servers never appear in discovery and the node is not listed publicly. Turn back on any time.

Support

The support forum lives in the #support channel. Users open one ticket per request (one per 48 hours); only you and node staff can see tickets.

Accepting new tickets
Off = users see your open hours instead of being able to file a ticket. Existing tickets stay open.
